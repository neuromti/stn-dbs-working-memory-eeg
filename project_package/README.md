# Project Package

This package contains reusable functions used by `main.py`.

- `files_management.py`: file discovery, filename automation, and measurement availability checks.
- `preprocessing.py`: EEG preprocessing, marker handling, epoching, and preprocessing summaries.
- `behavioral_features.py`: scoring for SDR, VDR, and oddball behavioral outputs.
- `physio_features.py`: P300 and time-frequency feature extraction.
- `statistics.py`: normalization, subsetting, correlation tables, and plotting helpers.
